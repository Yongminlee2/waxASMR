# 자산 만드는 도구

앱에 들어가는 소리와 그림을 만드는 파이썬 스크립트다. 평소에는 쓸 일이 없다 —
결과물(`app/src/main/assets/`)이 저장소에 함께 올라가 있어서 클론하면 바로 빌드된다.

다시 만들어야 할 때만 쓴다. numpy와 Pillow가 필요하다.

## 소리

| 스크립트 | 하는 일 |
|---|---|
| `segment.py` | 긴 녹음을 무음 기준으로 세션 단위로 자른다 |
| `refine.py` | 잘린 세션을 음색으로 묶어 재질 후보를 만든다 |
| `group.py` | 묶인 결과를 사람이 고른 대로 정리한다 |
| `buildbank.py` | 최종 덩어리 뱅크(`chunks.bin` / `chunks.idx`)를 만든다 |
| `chunks.py`, `extract.py`, `diag.py` | 중간 점검·진단용 |

원본 녹음(1.3GB짜리 wav)은 용량 때문에 저장소에 없다. 뱅크를 다시 만들려면
그 파일이 따로 있어야 한다. `original.pcm`은 그 녹음에서 잘라낸 90초다.

## 그림

| 스크립트 | 하는 일 |
|---|---|
| `gen_ball_textures.py` | 장난감·캐릭터 볼 16종 표면 |
| `gen_clay_textures.py` | 파스텔 마블 반죽 볼 6종 표면 |
| `planets_preview.py` | 행성 셰이더를 PC에서 미리 그려 본다 |

## 다국어

| 스크립트 | 하는 일 |
|---|---|
| `gen_i18n.py` | 언어별 `values-*/strings.xml` 을 만든다 |
| `gen_fr_ru.py` | 프랑스어·러시아어를 같은 규격으로 덧붙인다 |

두 스크립트 모두 **기존 언어에서 키 목록과 배열 길이를 읽어 강제한다.**
하나라도 빠지면 그 자리만 기본 언어(영어)로 떨어져 화면이 섞여 보인다.

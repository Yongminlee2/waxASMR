# 출시 절차

구글 플레이에 올릴 때 순서대로 하면 되는 것들. 앱 이름 **왁뿌볼 ASMR**,
패키지 **`com.waxball.asmr`** (한 번 등록하면 바꿀 수 없다).

## 1. 서명 키 만들기 (최초 한 번)

키와 비밀번호는 본인만 가지고 있어야 하므로 직접 만든다.
프로젝트 루트에서:

```
keytool -genkeypair -v -keystore waxball-release.jks -alias waxball -keyalg RSA -keysize 2048 -validity 10000
```

물어보는 것: 비밀번호(두 번), 이름·조직·도시·국가코드(KR). 조직은 비워도 된다.

그다음 `keystore.properties.example` 을 `keystore.properties` 로 복사하고
비밀번호를 채운다.

> **키를 잃어버리면 이 앱을 다시는 업데이트할 수 없다.** 만들자마자 `.jks` 파일과
> 비밀번호를 다른 곳에 백업할 것. 저장소에는 올라가지 않는다(.gitignore).

## 2. 출시 파일 만들기

```
build-release.bat
```

`app/build/outputs/bundle/release/app-release.aab` 가 나온다.
플레이 스토어는 APK가 아니라 **AAB**를 받는다 — 기기별로 쪼개 배포해서
사용자가 받는 용량이 훨씬 줄어든다.

키가 없으면 서명 없는 파일이 나오고 스토어가 거부한다. 1번을 먼저 해야 한다.

## 3. 콘솔에 올리기

Play Console → 앱 만들기 → 아래를 채운다.

| 항목 | 값 |
|---|---|
| 앱 이름 | 왁뿌볼 ASMR |
| 기본 언어 | 한국어 |
| 앱 또는 게임 | 앱 |
| 유료 또는 무료 | 무료 (결제 코드가 없다) |

**앱 콘텐츠**에서 채울 것:

- 개인정보처리방침: `https://yongminlee2.github.io/legal/waxball/privacy.html`
- 광고: 없음
- 앱 액세스: 제한 없음 (로그인이 없다)
- 데이터 보안: **수집·공유 없음**. 카메라 영상은 기기에서만 처리하고 저장·전송하지 않는다
- 콘텐츠 등급: 설문 진행 (폭력·성인 요소 없음)

**스토어 등록정보**에 필요한 그림:

| 항목 | 규격 |
|---|---|
| 앱 아이콘 | 512 × 512 PNG |
| 그래픽 이미지 | 1024 × 500 |
| 휴대전화 스크린샷 | 최소 2장 |

## 4. 버전 올리기

다음 판을 올릴 때는 `app/build.gradle.kts` 의 `versionCode` 를 반드시 올린다
(1 → 2 → 3 …). 같은 번호로는 업로드가 거부된다. `versionName` 은 사람이 보는
문자열이라 자유롭게 정한다.

## 확인해 둔 것

- 앱에 **인터넷 권한이 없다.** 데이터를 밖으로 보내는 것이 기술적으로 불가능하다
- 권한은 카메라(손 인식)와 진동뿐이다
- 소리 자산과 손 인식 모델이 저장소에 있어, 다른 컴퓨터에서 클론해 빌드해도
  같은 결과가 나온다
- arm64-v8a 한 종류만 싣는다. x86은 에뮬레이터용이라 뺐다

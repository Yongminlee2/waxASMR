# 스토어 자산

플레이 콘솔 **스토어 등록정보**에 올리는 그림들. 준비된 것과 직접 찍어야 하는 것이 있다.

| 파일 | 규격 | 콘솔의 어느 칸 |
|---|---|---|
| `../icons/_스토어_512.png` | 512×512 | 앱 아이콘 (필수) |
| `feature-graphic-1024x500.png` | 1024×500 | 그래픽 이미지 (필수) |

## 직접 찍어야 하는 것

### 휴대전화 스크린샷 — **준비 완료** (6장)

`phone/` 에 1080×2160 PNG 6장이 있다. 이 순서로 올린다.

| 파일 | 문구 |
|---|---|
| `01-palm.png` | 손바닥에 올려놓고 / 쥐어서 부수세요 |
| `02-squeeze.png` | 쥔 만큼 부서집니다 / 직접 녹음한 진짜 소리 |
| `03-dough.png` | 다 부순 뒤가 진짜 / 주무를수록 색이 섞여요 |
| `04-home.png` | 왁뿌볼 42종 / 행성부터 캐릭터까지 |
| `05-guide.png` | 점선에 손을 맞추면 / 바로 올라옵니다 |
| `06-shape.png` | 손 모양 그대로 / 볼도 함께 눌립니다 |

앞의 두 장이 검색 결과에 크게 뜬다.

**어떻게 만들었나** (`tools/make_store_shots.py`)

실제 앱 화면을 그대로 쓴다 — 없는 장면을 지어내면 심사에서 걸린다. 대신 앱
첫 화면과 같은 파스텔 배경에 문구를 얹고 그 안에 화면을 앉혔다. 화면이 작아지면서
배경에 찍힌 방바닥 같은 것이 덜 도드라지고, 무엇을 하는 앱인지가 글로 먼저 읽힌다.

폰 원본은 1080×2400인데 화면비가 2.22:1 이라 **구글 상한 2:1 을 넘어 그대로는
거부된다.** 재 보니 안드로이드 상태바가 위 78px, 내비바가 아래 130px 이라
둘을 걷어냈다 — 통신사·시계·배터리도 함께 사라진다.

**새로 찍을 때:** 폰에서 캡처해 아무 폴더에 모아 두고, 스크립트 맨 위의 `SRC`
경로와 `PICK` 목록(원본 번호·파일 이름·문구)만 고쳐 다시 돌린다.
스크린샷 편집 툴바가 찍힌 장면은 빼야 한다.

### 태블릿 스크린샷 — 선택

7인치·10인치 칸이 따로 있지만 **없어도 출시된다.** 태블릿이 없으면 건너뛴다.
넣으면 태블릿 사용자에게 노출이 조금 유리해지는 정도다.

## 콘솔에 올릴 때

**성장 → 스토어 설정 → 기본 스토어 등록정보** 아래쪽 그래픽 항목에 끌어다 놓는다.
언어별로 따로 넣지 않아도 되고, 안 넣으면 기본 언어(한국어) 것이 쓰인다.

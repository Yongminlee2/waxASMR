# 스토어 자산

플레이 콘솔 **스토어 등록정보**에 올리는 그림들. 준비된 것과 직접 찍어야 하는 것이 있다.

## 준비된 것

| 파일 | 규격 | 콘솔의 어느 칸 |
|---|---|---|
| `../icons/_스토어_512.png` | 512×512 | 앱 아이콘 (필수) |
| `feature-graphic-1024x500.png` | 1024×500 | 그래픽 이미지 (필수) |

## 직접 찍어야 하는 것

### 휴대전화 스크린샷 — **필수, 2~8장**

폰을 USB로 꽂고 앱을 원하는 화면에 둔 다음, 명령 한 줄로 찍는다.

```
capture.bat 01-home
```

`docs\store-assets\phone\01-home.png` 로 저장된다. 이름만 바꿔가며 반복한다.

> **에뮬레이터로는 못 찍는다.** 이 앱은 손 인식 라이브러리 때문에 arm64 전용으로
> 만들어져 있고, 보통 에뮬레이터는 x86_64다. 게다가 에뮬레이터에는 카메라 앞에
> 놓을 손이 없어서 정작 보여줄 화면이 안 나온다.

**찍으면 좋은 화면 (이 순서 권장):**

| 이름 | 무엇을 |
|---|---|
| `01-home` | 첫 화면. 볼 미리보기 카드가 예쁘게 보일 때 |
| `02-guide` | 카메라 켠 직후. 점선 손 안내선이 보이는 화면 |
| `03-ball-on-palm` | 손바닥 위에 볼이 올라온 순간 |
| `04-cracked` | 몇 번 쥐어 금이 가고 조각이 떨어진 상태 |
| `05-knead` | 다 부순 뒤 색이 섞여 가는 반죽 |
| `06-picker` | 볼 고르기 줄이 보이는 화면 (42종이 있다는 걸 보여 준다) |

첫 두 장이 검색 결과에 크게 뜨므로 제일 좋은 것을 1·2번에 둔다.

**규격:** 세로 화면 그대로면 된다. 짧은 변 320px 이상, 긴 변 3840px 이하,
가로세로비 2:1 이내. 요즘 폰 캡처는 전부 조건을 만족한다.

### 태블릿 스크린샷 — 선택

7인치·10인치 칸이 따로 있지만 **없어도 출시된다.** 태블릿이 없으면 건너뛴다.
넣으면 태블릿 사용자에게 노출이 조금 유리해지는 정도다.

## 콘솔에 올릴 때

**성장 → 스토어 설정 → 기본 스토어 등록정보** 아래쪽 그래픽 항목에 끌어다 놓는다.
언어별로 따로 넣지 않아도 되고, 안 넣으면 기본 언어(한국어) 것이 쓰인다.

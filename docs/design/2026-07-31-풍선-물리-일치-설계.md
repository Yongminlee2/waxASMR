# 풍선·물리 일치와 잔여물 소리 — 설계

## 지적받은 것과 원인

| 지적 | 원인 |
|---|---|
| 각진 볼에도 동그란 풍선이 씌워짐 | 풍선을 민짜 구 메시로 그린다. 볼 모양(`shape.warp`)을 안 탄다 |
| 잔여물을 쥐어도 소리가 안 남 | 껍질이 다 떨어지면 `pressArea`가 이벤트를 안 내고, 문지름 경로는 덩어리를 진폭 0.014로 틀어 사실상 무음 |
| 풍선이 뿌옇고 행성을 가림 | 알파 0.30 + 프레넬 증폭 + 크기 1.045배 |
| 풍선과 안의 것이 따로 놈 | 쥐면 갇힌 조각만 밀리고 풍선·껍질은 미동도 없다 |

## 고침 네 가지

**① 풍선이 볼 모양을 따른다.** 볼마다 풍선 메시를 따로 만든다 — 껍질과 같은
`shape.warp()`를 적용한 구. 주사위 볼엔 각진 풍선, 달걀 볼엔 달걀 풍선.

**② 눌림 변환 하나를 전부가 공유한다.** `uSquash`(깊이로 납작, 옆으로 살짝 부풂)를
껍질·속살·풍선 셰이더에 같이 걸고, 갇힌 조각의 우리(안쪽 반지름)도 같은 비율로
줄인다. 볼 중심 기준이라 자리는 안 움직인다. 쥐는 세기는 `PalmPose.squeeze`를
0.25~1.0 → 0~1로 다시 매겨 쓴다(편 손에서도 0.2쯤 나오는 보정 오차를 걷어냄).

**③ 풍선을 투명하고 딱 맞게.** 크기 1.045 → 1.02, 기본 알파 0.30 → 0.12,
반짝임 완화. 행성이 또렷이 보이고 가장자리에만 막이 비친다.

**④ 잔여물 소리.** 쥐는 힘이 있고 떨어진 조각이 있으면 문지름 이벤트를 보낸다.
덩어리 모드의 문지름은 "이미 울리는 중이면 안 얹고, 조용할 때만 절반 진폭으로 하나"로
고친다. 문지름은 프레임마다 오므로 얹으면 순식간에 쌓여 뭉갠다.

## 파일

- `gl/Shaders.kt` — 껍질·코어 정점 셰이더에 `uSquash`(코어는 `uOffset` 기준, 껍질은 `uCenter` 추가)
- `gl/BallRenderer.kt` — 볼별 풍선 메시, `setSquash`, 풍선 상수
- `gl/TrappedShards.kt` — `setCage(scale)` + 검증용 `radiusOf`
- `audio/Synth.kt` — 덩어리 모드 문지름 게이트
- `ar/ArPlayActivity.kt` — 배선 (스쿼시·우리·잔여물 문지름)

## 테스트 (PC)

- 우리를 줄이면 조각이 그 안으로 모이는지 (`TrappedShards`)
- 문지름 덩어리가 겹쳐 쌓이지 않는지, 조용할 때만 하나 트는지 (`Synth`)

풍선 모양·투명도·눌림의 보이는 결과는 기기 확인.
